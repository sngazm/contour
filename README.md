# TOPOPO

等高線で示された広い地形を、スマホで歩くミニマルなブラウザゲーム。
（デス・ストランディングに影響を受けつつ、極限まで言葉を削ったプロトタイプ置き場）

公開URL（ルート）は**バージョン一覧ページ**。各版の更新内容を一言ずつ載せ、
タップでその版を遊べます（過去版は当時のまま凍結）。

## 遊び方（言葉なしの設計）

- 画面は円形に切り取られ、地形は**等高線**で示される。カメラは真上からのオルソ。
- プレイヤーは中央の白い丸。**画面をドラッグ**（PCは矢印/WASDも可）すると、引っ張った方向へ進む。
- カメラが追従して地形がスクロールする。
- **視界は常に視線遮蔽される**。各方角で地形が「自分の高さ＋約3本ぶんの等高線」を超えると、
  その先は尾根に遮られて見えない（圏外は白地図ふうに伏せる）。足元の小さな輪だけは常に見える。
  **見通せる距離に上限はなく**、高い所に登るほど遠くまで見渡せる＝高い峰に登れば、さらに高い峰が見える。
- **ズームアウトはレーダー消費制**。レーダーを拾うと右下に**レーダーボタン**が出る。押すと一度だけ
  マップ全域を引きで偵察できる（カメラはマップ中心基準・最高地点が枠外にならない）。
  **動き出すと偵察は解除**。止まって地形を読み、次の目的地へのルートを考える。
- **坂を登るほど遅く、下るほど速い**。等高線が密なところ＝急斜面。
  進行方向の線は**実速度に応じて伸縮**する（急登でゆっくり＝短い／下りで加速＝長い）。
- 地形は**高度カラー4色**（下から 青→緑→黄土→白）で塗り、**尾根谷度の陰影**（谷=暗／尾根=明）を重ねる。
  ズームアウトしても色で高所（白）がすぐ分かる。傾斜は等高線が担う。
- **急な崖**では踏ん張れず**転がり落ちる**（手を離す／急すぎて登れないと発動）。
  転落中は操作不能（中央の印がぐるぐる回る）。緩斜面まで落ちると停止し、
  **落下時間に応じて1〜3秒の放心**（操作不能。減るリングで表示）してから復帰。グローブがあれば崖でも転落しにくい。
- **NPC（競争者）は現在オフ**（v25で一旦無効化。コードと挙動は残置）。以下は再有効化時の仕様：
- フィールドには**NPC**がいる。彼らも高い所を目指すが視野が狭く、**周辺の広い範囲を見渡して**より高い所へ登る。
  プレイヤーが見えて近いと**追ってきて突き落とす**（＝転落＋放心）。追跡中の個体は赤い輪で表示。
  - NPCは**自分の標高±3等高線の範囲しか見えない**。高い尾根の陰にも、**3等高線以上低い低地**にも隠れられる。見失うとすぐ諦める。
  - 各NPCには**進行方向の線**が出る（追跡中は赤）。
  - 逆に**こちらが速度を乗せて突っ込む**（下り疾走やジップ）と**NPCを突き落とせる**。倒したNPCは消えず、**クルクル回りながら転がり落ち**、6秒ほど放心して復帰。
  - **一度突き落とされると敵全員が満足してしばらく登りに戻る**。さらに放心から**復帰直後は少しの間突かれない**（取り囲みハメ防止）。
- フィールドには2種類の寄り道目標が点在（歩いて重なると取得）：
  - **レーダー**（青緑の同心円・**谷に多い**）：1回ぶんのズームアウト偵察。残数は左下に表示。
  - **ボーナス**（金の星・**尾根や高所に多い**）：取ると ✦ が増え、**制限時間が延びる**（+6秒）。寄り道する価値の別軸。
  最高地点へ最短で登るか、谷のレーダーや尾根のボーナスへ寄り道するか――ルート構築の悩みどころ。
  最高地点はプレイ中ずっと隠れていて、自分の足と偵察で探し出す（探索の肝）。
- 縁のリングが残り時間。**60秒**で1ゲーム。フィールドの縁（**破線の円**・外側は陰る）の外には出られない。
- 移動中に**画面中央（自分）をタップ**すると、その場に**旗を立てて即終了**（残り時間を待たずに記録を確定してリザルトへ）。
- 画面上には常に数値。**★＝自己記録（到達した最高高度）/ ▲＝フィールド最高（目標）/ ●＝現在地 / ✦＝ボーナス数**。
- 左端に**縦型の高度計**（上端＝フィールド最高。4色の段彩スケール）。現在地・記録(★)・目標(▲)の高さがひと目で分かる。
- **テーマは探索＝最高点を探し出すルート構築**。手近な高所に登り、眺めから次に登る所を探す。
  急な崖を避けるか攻めるかを地形から悩んで道を切り開く。高所ほど価値が高いがリスク（崖・転落）も増す。
- スコアは**到達した最高高度**。**今より高い所に行く＝記録更新＝達成**（その瞬間に演出）。
  中堅で粘っても記録は伸びない。降りても記録は減らないので「より高い所へ降りて挑む」が安心して狙える勇気ある一手になる。
- 終了すると視点が斜め上に変わり、地形が**高度カラー＋陰影で塗られた立体**で現れる（WebGLシェーダーでピクセル単位に塗るので色帯・等高線の境界が滑らか）。
  通ってきた**軌跡**（角度に依らず一定太さのパイプ・角は丸く接合。深度テストで山の陰に隠れる）と到達点、**自己記録（★）と ✦** が出る。
  **金色のビーコン**がフィールドの最高地点（行けたかもしれない場所）。
- リザルトは**1本指で回転（orbit・慣性あり）／2本指・ホイールでズーム／タップで再挑戦**。

## 構成

```
index.html              バージョン一覧ページ（ハブ）
versions.json           一覧の元データ（版・日付・一言・リンク）
src/                    開発中の最新版が使う共有エンジン
  util.js               乱数 / 補間 / 標高パレット
  terrain.js            回転付きバリューノイズ(fBm)の連続地形（高さ・勾配を解析的に算出）
  contours.js           マーチングスクエア法の等高線抽出
  input.js              フローティング仮想スティック + キーボード
p/01-contour/           最新版（src/ を読み込む。次の版もここで開発）
  index.html
  game.js               ループ / 円窓トップダウン描画 / 斜め俯瞰リプレイ
p/v1/  p/v2/  ...        過去版の凍結スナップショット（自己完結・当時のまま）
```

ゲームの数値（時間・速度・坂の効き・等高線間隔など）は
`p/01-contour/game.js` 冒頭の `CFG` でまとめて調整できます。

## ローカル確認

ES モジュールを使うため `file://` では動きません。簡易サーバで開いてください。

```bash
npm run dev     # http://localhost:5173 を開く
```

（Node が無くても、任意の静的サーバでリポジトリ直下を配信すればOK）

## Cloudflare Pages へのデプロイ（push で自動）

ビルド工程はありません。Pages の Git 連携を一度だけ設定すれば、以降は
このリポジトリへの push で自動デプロイされます。

1. Cloudflare ダッシュボード → **Workers & Pages** → **Create** → **Pages**
   → **Connect to Git** で本リポジトリ（`sngazm/contour`）を選択。
2. ビルド設定:
   - **Framework preset**: `None`
   - **Build command**: （空のまま）
   - **Build output directory**: `/`
3. デプロイ対象ブランチを指定して保存。以降、push するたびに自動公開されます。

> シークレット登録は不要です。プレビュー用に他ブランチを追加することもできます。

## バージョンの増やし方

最新版は `p/01-contour/`（`src/` を読み込む）で開発します。
区切りのいい更新をしたら、次の手順で「版」を確定します。

1. 現在の `p/01-contour/` を凍結スナップショット化する
   （`src/` の各モジュールをコピーしてフォルダに同梱し、import を `./` に書き換え、
   `p/vN/` として保存。当時のまま遊べる自己完結フォルダになる）
2. `versions.json` の先頭に新しい版を追加し、ひとつ前の版の `latest` を外して
   `href` を凍結フォルダ（`./p/vN/`）に向ける
3. 引き続き `p/01-contour/` を次の版として開発

ルートの一覧ページは `versions.json` を読むだけなので、データを足せば反映されます。
